# 新規ストリーマーテーマ案 A〜Z（Next.js版）

**メインターゲット**: VTuber / ゲーム配信者（Twitch/YouTube） / Vライバー  
**コンセプト**: ゲームジャンル特化 × VTuberの世界観表現  
**技術**: Next.js + React + GSAP + React Three Fiber（必要時のみ）

## 共通設計ルール

- 個別テーマの詳細設計は `docs/TEMPLATE_DESIGN_SPEC_COMMON.md` を正本にする
- 共通骨格は Hero / Profile / Content / Schedule / Contact / Footer を基本にする
- 各テーマ設計では、`LP single page` / `LP + subpages` / `subpage-centered` のどれかを必ず明記する
- PC のヘッダー位置は `top fixed` / `side panel` / `floating overlay` のどれかを必ず明記する
- ナビゲーション形式と下層ページ有無も、各テーマ設計で個別に書く
- 3D は必須ではなく、テーマの核に必要なものだけ採用する
- モバイルでは演出量を落としても、世界観の理解と CTA は保つ
- 各テーマ設計では、色・フォント・主役の体験・フォールバックを先に固定する
- 既存テンプレートは残したまま、新規テーマとして実装する
