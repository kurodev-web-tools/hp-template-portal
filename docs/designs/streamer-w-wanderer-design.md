## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 放浪の道筋を 1 ページで見せる

### 3.2 トップの役割

- 旅の起点としての雰囲気を作る
- 旅人の人柄、旅路、地図、接点を 1 画面で伝える
- 詳細な記録は増やしすぎず、旅程として見せる

### 3.3 ヘッダー位置

- `floating overlay`
- 地図やコンパスと重ならない軽いナビにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- 地図やコンパスをそのまま導線にする
- 現在地と目的地が分かる旅の UI として見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Map / Journey / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では地図の広がりと旅の奥行きを活かす
- SP では道標を簡略化し、迷いにくい導線にする
- PC は広い地図とルートを見せる
- SP はルートを短くし、現在地が見えるようにする

```
index.html
├── Section 1: Hero (砂漠)
├── Section 2: Profile (旅人)
├── Section 3: Map (地図)
├── Section 4: Dungeon (ダンジョン)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、旅程の章立てで完結させる
- `Map` は地図、`Dungeon` は寄り道、`Contact` は次の目的地への接点として扱う
