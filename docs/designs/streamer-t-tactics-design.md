## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 戦略ゲームの盤面を 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で盤面の把握しやすさを伝える
- 情報を整理して、選択肢の多さを見せる

### 3.3 ヘッダー位置

- `top fixed`
- グリッド上でも崩れにくい標準ヘッダーにする

### 3.4 ナビゲーション形式

- `section cards`
- ターンやマップ選択のように移動させる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Units / Battle / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では盤面とユニット情報の配置を優先する
- SP ではカード数を抑え、ターン進行が見やすい構成にする

```
index.html
├── Section 1: Hero (マップ全体)
├── Section 2: Profile (指揮官)
├── Section 3: Units (ユニット紹介)
├── Section 4: Classes (クラス)
└── Section 5: Contact
```
