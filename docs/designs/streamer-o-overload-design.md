## 3. ページ構成

### 3.1 レイアウトモード

- `LP + subpages`
- コクピットの主画面に加えて、格納庫や戦績を別導線で見せる

### 3.2 トップの役割

- 起動中のコクピット視点を提示する
- 現在の機体、パイロット情報、主要 CTA を 1 画面で見せる
- 詳細な機体一覧や戦闘記録は下層へ逃がす

### 3.3 ヘッダー位置

- `side panel`
- HUD サイドバーをヘッダー兼ナビゲーションとして扱う

### 3.4 ナビゲーション形式

- `world-in-UI`
- 「WEAPON」「ARMOR」「HANGAR」などのシステム名で移動させる
- トップの HUD と下層ページ導線を同じ機械 UI として見せる

### 3.5 下層ページ構成

- `hangar`: 所有機体、格納庫、装備の一覧
- `battle log`: 戦闘記録、戦績、最近の出撃ログ
- `profile`: パイロットデータ、所属、操縦スタイル
- `loadout`: 必要なら装備構成の詳細を追加する
- トップに置かない項目: 個別機体の長文説明、戦闘履歴の全件表示

### 3.6 PC / SP の見せ方

- PC ではコクピットの横幅と HUD の固定表示を優先する
- SP ではコクピット感を維持しつつ、情報は縦積みに寄せる
- PC は左右の HUD パネルと中央ビューアーを主役にする
- SP は HUD を最小化し、機体情報の読み順を明確にする

```
index.html
├── Section 1: Hero (起動シークエンス)
├── Section 2: Profile (パイロットデータ)
├── Section 3: Mecha (機体/メカ紹介)
├── Section 4: Battle (戦闘記録)
├── Section 5: Hangar (格納庫)
└── Section 6: Contact
```

### ナビゲーション

**HUDサイドバー**
- 左右にHUDパネル
- 各セクションがシステム名で表示（「WEAPON」「ARMOR」等）
- アクティブでハイライト

### 3.7 下層ページの位置づけ

- `hangar` は機体選択と装備確認のためのページ
- `battle log` は戦歴と実績の確認のためのページ
- `profile` はパイロット情報の深掘りページ
- `loadout` は必要時のみ追加する詳細補助ページ
- トップページは「起動中の現在地」を見せる役割に留める

## 4. セクション詳細

### Section 1: Hero

**レイアウト**: コクピット視点

**構成**:
1. **フレーム**: コクピットの窓枠
2. **HUD**: バイザーに表示される情報（照準、レーダー、装甲値）
3. **外**: 宇宙/戦場が見える
4. **中央**: 「SYSTEM STARTUP」テキスト

**3D要素**:
```typescript
// コクピットフレーム
const CockpitFrame = () => {
  // パイロット席の周りのメカニカルな枠
  // 配線、ボルト、パネル
};

// HUD表示
const HUD = () => {
  // 照準レティクル（中央）
  // レーダー（右上）
  // 装甲ゲージ（左）
  // 武器状態（右）
};

// スラスター噴射
const Thruster = () => {
  // 加速時のエフェクト
  // 画面の揺れ
  // 青白い光
};
```

**アニメーション**:
```javascript
// 起動シークエンス
// SYSTEM BOOT → CHECK → ONLINE
// HUDが順に点灯

// スラスター
// 加速時に画面が揺れる
// 後方から光が来る
```

### Section 2: Profile

**レイアウト**: パイロットデータベース

**構成**:
- パイロット名（コールサイン）
- 階級（新兵/熟練/エース等）
- 搭乗機数
- 総戦闘時間
- キル数（敵機撃墜数）
- 得意な機体タイプ

**表示**:
- 軍隊式データベース
- 写真（パイロットスーツ着用）
- スタンプ（勲章）

### Section 3: Mecha

**レイアウト**: 機体紹介（3Dビューアー）

**構成**:
- 現在の愛機
- 機体名、型式番号
- 装備武器
- アーマー値
- スピード、機動性

**3D演出**:
- 機体が回転
- 部位別にクリックで詳細
- 武器展開アニメーション

### Section 4: Battle

**レイアウト**: 戦闘ログ

**構成**:
- 最近の戦闘記録
- 使用機体、敵機、結果
- ダメージ量
- バトルクリップ
