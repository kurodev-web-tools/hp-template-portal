## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 量子と時空の重なりを 1 ページで見せる

### 3.2 トップの役割

- 重ね合わせの世界に入った瞬間の知的な印象を作る
- 観測者としてのプロフィールと、状態変化の導線を見せる
- 詳細な時系列や並行世界はトップ内の章で回す

### 3.3 ヘッダー位置

- `top fixed`
- グリッド空間の上に安定して置けるナビにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- 波動関数や座標系の UI を導線として見せる
- ナビゲーション自体を量子状態の切替に見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / States / Timeline / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では重ね合わせと空間の広さを出す
- SP では情報の重なりを減らし、読み順を明確にする
- PC は広いグリッドと複数状態の重なりを見せる
- SP は状態数を減らし、ひとつずつ観測できる構成にする

```
index.html
├── Section 1: Hero (重ね合わせ)
├── Section 2: Profile (観測者)
├── Section 3: Wave（波動関数）
├── Section 4: Parallel (並行世界)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、状態遷移の章立てで完結させる
- `States` は存在の変化、`Timeline` は時系列、`Contact` は観測後の接点として扱う
