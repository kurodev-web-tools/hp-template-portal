## 1. 基本情報

| 項目 | 内容 |
|------|------|
| **テーマコード** | B |

## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 1 ページで弾幕 STG の流れを見せる

### 3.2 トップの役割

- 弾幕 STG の強い初速を 1 画面目で伝える
- メニューよりも、スペルカード感と戦闘開始のテンションを優先する

### 3.3 ヘッダー位置

- `floating overlay`
- 画面外周の HUD と干渉しない薄いナビゲーションにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- メニューがスペルカード選択そのものとして見える構成にする

### 3.5 下層ページ構成

- なし
- 情報はトップ内のセクションで完結させる

### 3.6 PC / SP の見せ方

- PC では弾幕の密度と HUD の存在感を優先する
- SP では弾幕を軽くし、カードと CTA を先に読めるようにする

```
index.html
├── Section 1: Hero (ボス戦)
├── Section 2: Profile (自機紹介)
├── Section 3: Spell Cards (スペカ紹介)
├── Section 4: History (戦績)
├── Section 5: Stream
└── Section 6: Contact
```

### ナビゲーション

**スペルカード選択**
- メニューがスペルカード風
- 各項目がカードとして表示
- 選択でカードが光る

## 4. セクション詳細

### Section 1: Hero

**レイアウト**: 弾幕STG画面

**構成**:
- **背景**: 時空の歪み、魔法陣
- **弾幕**: 無数の弾がパターンを描く（Three.js）
- **自機**: 配信者アイコンが中央で揺れる
- **ボス**: 大きな魔法陣が奥に

**3D要素**:
```typescript
// 弾幕パターン
const Danmaku = () => {
  // 螺旋、全方位、レーザー等のパターン
  // 50-100個の弾が同時に動く
  // 美しい幾何学模様を描く
};
```

**アニメーション**:
- 弾が螺旋、放射、レーザー等のパターンで動く
- 自機がマウス/スクロールに連動して避ける

### Section 2: Profile

**レイアウト**: 自機選択画面風

**構成**:
- 自機（配信者）のスペック
- ショットタイプ
- スペルカード性能
- 残機（配信頻度）

### Section 3: Spell Cards

**レイアウト**: スペルカード一覧

**構成**:
- 各配信シリーズがスペルカード名
- 難易度表示（Easy/Normal/Hard/Lunatic）
- カードアート風サムネイル
