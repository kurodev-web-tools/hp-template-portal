## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 地獄の召喚体験を 1 ページで完結させる

### 3.2 トップの役割

- 召喚直後の存在感を最初に見せる
- 業火、魔法陣、翼の強さで配信者像を伝える
- プロフィールや契約情報は、トップ内の章で順に開示する

### 3.3 ヘッダー位置

- `floating overlay`
- 炎や魔法陣を邪魔しない軽い固定ナビにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- 炎のリングをシステム UI として使う
- ナビゲーションは召喚陣の外周に溶け込ませる

### 3.5 下層ページ構成

- なし
- Profile / Powers / Contract / Throne はトップ内で完結させる
- 追加ページは持たず、章の切替で見せ切る

### 3.6 PC / SP の見せ方

- PC では中央召喚の迫力と周囲の炎を広く見せる
- SP では炎の密度を落とし、配信者名と CTA を優先する
- PC では魔法陣の奥行きと炎の層を大きく見せる
- SP ではエフェクトを抑え、真名より見出しと CTA を優先する

```
index.html
├── Section 1: Hero (召喚)
├── Section 2: Profile (悪魔の正体)
├── Section 3: Powers (魔力・スキル)
├── Section 4: Contract (契約)
├── Section 5: Throne (王座)
└── Section 6: Contact
```

### ナビゲーション

**炎のリング**
- 右側に炎のリングが浮かぶ
- スクロールで炎が上昇
- 各セクションで炎の色が変化

1. **背景**: 地獄の業火、溶岩

### Section 2: Profile

**レイアウト**: 悪魔のデータ

**構成**:
- 真名（人間には発音不可）
- 年齢（XXX歳）
- 位階（子爵/伯爵/公爵等）
- 魔力レベル
- 得意な属性（火/闇/呪い）
- 好物（魂のエネルギー等）

**レイアウト**: スキルツリー風

**構成**:
- 魔力スキル（火球、闇の刃等）
- 各スキルの威力
- 必殺技（アルティメット）
