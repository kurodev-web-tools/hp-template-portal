## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 星幽体と地上の二層構造を 1 ページで見せる

### 3.2 トップの役割

- 星幽体としての第一印象を作る
- 地上と星界の二層を 1 画面で理解できるようにする
- オーブ導線で、プロフィールと活動情報へ自然に入らせる

### 3.3 ヘッダー位置

- `floating overlay`
- オーブの浮遊感を崩さない軽い固定ナビにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- オーブ型ナビをそのまま移動導線として使う

### 3.5 下層ページ構成

- なし
- Hero / Profile / Aura / Journey はトップ内で完結させる
- 詳細なページ分割はせず、二層構造の章立てで完結させる

### 3.6 PC / SP の見せ方

- PC では上下二層と奥行きを活かして、浮遊感を強める
- SP では二層表現を簡略化し、テキストと CTA を先に読めるようにする
- PC では地上と星界の差を明確に見せる
- SP では階層差を弱め、プロフィールと CTA を先に読めるようにする

```
index.html
├── Section 1: Hero (星幽体出現)
├── Section 2: Profile (霊媒師/媒介者)
├── Section 3: Aura (オーラ診断)
├── Section 4: Journey (星界旅行記録)
├── Section 5: Contact
```

### ナビゲーション

**オーブ型ナビ**
- 右側に霊的なオーブが浮遊
- 各オーブがセクションを示す色を持つ
- スクロールでオーブが導く

## 4. セクション詳細

### Section 1: Hero

**レイアウト**: 二層構造（地上と星界）

**構成**:
1. **下層（地上）**: 暗く、ぼやけた肉体のシルエット
2. **上層（星界）**: 輝く星幽体の配信者
3. **間**: オーブが繋ぐ橋
4. **背景**: 深い霊的空間、遠くに他の星幽体

**3D要素**:
```typescript

const AstralBody = () => {
  // 半透明で光る人型
  // オーラが周囲に漂う
  // ふわふわと浮遊
};

// オーブ
const SpiritOrbs = () => {
  // 大小さまざまなオーブ
  // 導くように動く
  // 色が変化（感情に応じて）
};

// オーラ波動
const AuraWaves = () => {
  // 同心円状に広がる波動
  // チャクラの7色
};
```

**アニメーション**:
```javascript
// 星幽体が浮遊
y: sin(time) * 0.2
opacity: 0.7 + sin(time) * 0.3

// オーブが導く
move along path
leave trail

// オーラが広がる
scale: 1 → 10
opacity: 0.5 → 0
```

### Section 2: Profile

**レイアウト**: 霊媒師のプロフィール

**構成**:
- 霊媒師としての経歴
- 能力（透視、予知、霊視等）
- チャクラの開放度（7つのチャクラ）
- オーラカラー診断結果

**演出**:
- 7つのチャクラが点灯
- 各チャクラに色と意味
- オーラが写真の周りに

**レイアウト**: オーラ可視化

**インタラクション**:
- オーラカラーをクリックで詳細
- グラデーションで変化
