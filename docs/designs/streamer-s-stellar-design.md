## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 星座と星占いを 1 ページで完結させる

### 3.2 トップの役割

- 星座盤に入るような導入を作る
- 配信者の世界観、星読み、配信導線を 1 画面で伝える
- 詳細な補足は足しすぎず、天体の流れとして見せる

### 3.3 ヘッダー位置

- `side dots`
- 星の並びのように縦の導線を置く

### 3.4 ナビゲーション形式

- `side dots`
- 星座ラインに沿ってセクション移動する
- 星の並びそのものを移動導線にする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Constellations / Horoscope / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では星空の広がりと天体配置を活かす
- SP では星の数を絞り、可読性と導線を優先する
- PC は星座とホロスコープのレイヤーを広く見せる
- SP は星座線を減らし、導線を追いやすくする

```
index.html
├── Section 1: Hero (星空)
├── Section 2: Profile (星読み)
├── Section 3: Constellations (星座)
├── Section 4: Horoscope (星占い)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、星座と星占いの章立てで完結させる
- `Profile` は星読みの入口、`Constellations` は星座図鑑、`Horoscope` は鑑定結果として扱う
