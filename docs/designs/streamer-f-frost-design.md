## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 雪山の一枚絵として見せる

### 3.2 トップの役割

- 雪山に立つ印象を作る
- 氷の静けさで配信者像を見せる
- 作品や活動は、雪景色の章立てで無理なく伝える

### 3.3 ヘッダー位置

- `top fixed`
- 冷たい背景の上でも読みやすい標準ヘッダーにする

### 3.4 ナビゲーション形式

- `side dots`
- 霜の結晶のような縦導線でセクション移動する

### 3.5 下層ページ構成

- なし
- Hero / Profile / Ice / Aurora / Contact はトップ内で完結させる
- 追加の下層ページは作らず、氷雪の見せ場を章立てで持たせる

### 3.6 PC / SP の見せ方

- PC では余白と奥行きで極寒の広がりを見せる
- SP では演出を軽くし、氷の見た目より可読性を優先する
- PC では氷の質感と余白で冷気を見せる
- SP では雪の密度を減らし、説明文と CTA を優先する

```
index.html
├── Section 1: Hero (雪山)
├── Section 2: Profile (氷の魔法使い)
├── Section 3: Ice (氷の彫刻)
├── Section 4: Aurora (オーロラ)
└── Section 5: Contact
```
