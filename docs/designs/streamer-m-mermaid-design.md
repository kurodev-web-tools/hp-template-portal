## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 海洋の深さを 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で深さと浮遊感を伝える
- 静かな広がりを先に見せ、導線は穏やかにする

### 3.3 ヘッダー位置

- `floating overlay`
- 水面上に浮かぶ軽いヘッダーにする

### 3.4 ナビゲーション形式

- `side dots`
- 泡が浮かぶような縦ナビにする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Ocean / Gallery / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では水中の広がりと屈折を活かす
- SP では泡や背景演出を軽めにして、情報を見やすくする

```
index.html
├── Section 1: Hero (海底宮殿)
├── Section 2: Profile (人魚姫)
├── Section 3: Ocean (海の仲間たち)
├── Section 4: Treasures (宝物庫)
└── Section 5: Contact
```
