## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- ネオンとホログラムの空間を 1 ページで見せる

### 3.2 トップの役割

- サイバーシティに入ったときの速度感を作る
- 配信者の情報、システム感、通知導線を 1 画面で見せる
- 詳細情報は詰め込みすぎず、都市の層として扱う

### 3.3 ヘッダー位置

- `floating overlay`
- サイバー空間の上に浮かぶ軽い導線にする

### 3.4 ナビゲーション形式

- `world-in-UI`
- ホログラム UI をそのままナビに使う
- 画面上のシステムメニューそのものを移動導線にする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Grid / Systems / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC ではグリッド床と光のラインを活かす
- SP ではネオンの量を減らし、導線を読みやすくする
- PC は横に広い都市空間を作る
- SP は光量を抑え、見出しと CTA を先に見せる

```
index.html
├── Section 1: Hero (サイバーシティ)
├── Section 2: Profile (サイバー配信者)
├── Section 3: Neon (ネオン)
├── Section 4: Hologram (ホログラム)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、都市の章立てで完結させる
- `Grid` は都市の骨格、`Systems` は機能メニューとして扱う
