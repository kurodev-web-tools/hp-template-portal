## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 影の移動と忍びの気配を 1 ページで見せる

### 3.2 トップの役割

- 影の中に溶け込む忍者像を作る
- 隠密性、術、装備、接点を 1 画面で伝える
- 詳細説明は増やしすぎず、動きと気配で読ませる

### 3.3 ヘッダー位置

- `floating overlay`
- 竹林や影を邪魔しない軽い導線にする

### 3.4 ナビゲーション形式

- `world-in-UI`
- 手裏剣や忍具のような UI として見せる
- ナビ自体を忍具の選択UIとして見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Shadow / Tools / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では縦横の視線移動で潜伏感を出す
- SP では操作性を優先し、影の演出を軽くする
- PC は横方向の視線移動で潜伏経路を見せる
- SP は余白を確保し、忍術の見出しを先に読めるようにする

```
index.html
├── Section 1: Hero (影)
├── Section 2: Profile (忍者)
├── Section 3: Jutsu (術)
├── Section 4: Weapons (忍具)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、忍術の章立てで完結させる
- `Profile` は人物像、`Shadow` は潜伏、`Tools` は装備、`Contact` は接触口として扱う
