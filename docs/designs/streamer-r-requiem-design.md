## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 古城サロンを 1 つの流れで見せる

### 3.2 トップの役割

- 1 画面目で静かな祈りと格調を立たせる
- 装飾よりも余韻を先に見せる

### 3.3 ヘッダー位置

- `top fixed`
- 燭台や装飾とぶつからない上部固定ナビにする

### 3.4 ナビゲーション形式

- `side dots`
- 縦の燭台列で章移動を見せる

### 3.5 下層ページ構成

- なし
- Castle / Rose Garden / Blood Memory はトップ内の章で完結させる

### 3.6 PC / SP の見せ方

- PC では左右の余白と装飾を活かして耽美さを出す
- SP では装飾を減らし、文字と CTA を先に読めるようにする

```
index.html (LP風シングルページ)
├── Section 1: Hero (月の間)
├── Section 2: Profile (吸血鬼の正体)
├── Section 3: Castle (古城案内)
├── Section 4: Rose Garden (薔薇園)
├── Section 5: Blood Memory (記憶)
└── Section 6: Contact
```

### ナビゲーション

**燭台型ドットナビ**
- 右側に燭台が並ぶ
- 炎が揺らめく（スクロールで色変化）
- アクティブなセクションで炎が強くなる
