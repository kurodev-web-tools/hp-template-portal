## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- FPS HUD の緊張感を 1 ページで完結させる

### 3.2 トップの役割

- 1 画面目で緊張感と切れ味を出す
- 余白を残し、強い印象を一点集中で見せる

### 3.3 ヘッダー位置

- `top fixed`
- 戦術 UI の邪魔にならない最小ヘッダーにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- ミニマップや HUD と一体化した導線にする

### 3.5 下層ページ構成

- なし
- クリップや実績はトップ内で見せる

### 3.6 PC / SP の見せ方

- PC では四隅の HUD を活かし、画面全体を戦場にする
- SP では HUD を圧縮し、照準と主要 CTA を最優先にする

```
index.html (LP風)
├── Section 1: Hero (戦場投入)
├── Section 2: Profile (オペレーター)
├── Section 3: Loadout (武器構成)
├── Section 4: Stats (戦績)
├── Section 5: Highlights (クリップ)
└── Section 6: Contact
```

### ナビゲーション

**タクティカルミニマップ**
- 右上に円形ミニマップ
- セクションが敵アイコンとして表示
- アクティブな方向にピング

## 4. セクション詳細

### Section 1: Hero

**レイアウト**: フルスクリーンFPS視点

**構成**:
1. **中央照準**: 常に表示されるレティクル
2. **周囲**: 戦場の煙、火花、弾痕
3. **四隅**: 
   - 左上：HPバー
   - 右上：ミニマップ/キルフィード
   - 左下：武器アイコン
   - 右下：弾薬カウント

**3D要素**:
- 銃口のマズルフラッシュ
- 飛び散る弾殻
- 煙と火花パーティクル

**アニメーション**:
- 照準が呼吸で上下
- キルフィードが上から流れる
- 武器リロードアニメーション

### Section 2: Profile

**レイアウト**: オペレータープロフィール風

**構成**:
- コールサイン（配信者名）
- 階級/ランクアイコン
- K/Dレシオ
- 得意レジェンド/エージェント
- メイン武器

**演出**:
- 軍隊式IDカードデザイン
- スタンプが押されるアニメーション

### Section 3: Loadout

**レイアウト**: 武器選択画面風

**構成**:
- メイン武器（アサルト/スナイパー/等）
- サブ武器
- タクティカル（グレネード等）
- 各武器の3Dモデル表示

**インタラクション**:
- 武器をクリックで詳細スペック
- 3Dモデルが回転

### Section 4: Stats

**レイアウト**: 戦績ボード

**構成**:
- 総キル数
- ヘッドショット率
- 平均ダメージ
- 勝率
- グラフで時系列表示

### Section 5: Highlights

**レイアウト**: キルクリップ一覧

**構成**:
- クリップサムネイル
- キル数（トリプル、エース等）
- 日付・ゲーム

**演出**:
- 「HEADSHOT」「MULTI KILL」テロップ

## 5. 機能仕様

| 機能 | 説明 | 技術 |

| **照準レティクル** | 中央に常時表示 | CSS + Canvas |
