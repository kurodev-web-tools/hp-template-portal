## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 天界の静けさを 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で完成度と到達点の高さを示す
- クリーンで強い印象を先に置く

### 3.3 ヘッダー位置

- `top fixed`
- 光の柱や雲とぶつからない安定した導線にする

### 3.4 ナビゲーション形式

- `side dots`
- 天上の階層を意識した縦導線にする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Ascent / Light / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では余白と高低差で神聖さを出す
- SP では演出を最小化し、静かな可読性を保つ

```
index.html
├── Section 1: Hero (天国の門)
├── Section 2: Profile (天使)
├── Section 3: Hierarchy (天使の位階)
├── Section 4: Blessings (祝福)
└── Section 5: Contact
```
