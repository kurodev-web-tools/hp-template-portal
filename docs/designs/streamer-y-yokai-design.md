## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 百鬼夜行の流れを 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で和の気配と怪異の連なりを示す
- 物語性を先に置き、導線は静かに見せる

### 3.3 ヘッダー位置

- `top fixed`
- 提灯や絵巻の上に置ける安定した導線にする

### 3.4 ナビゲーション形式

- `side dots`
- 行列のように章移動を見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Parade / Stories / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では絵巻の流れと提灯の奥行きを見せる
- SP では余白と文字の読みやすさを優先する

```
index.html
├── Section 1: Hero (百鬼夜行)
├── Section 2: Profile (妖怪の正体)
├── Section 3: Parade (妖怪図鑑)
├── Section 4: Stories (怪談)
└── Section 5: Contact
```
