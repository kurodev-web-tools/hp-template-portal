## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 鏡の迷路を 1 ページで体験させる

### 3.2 トップの役割

- 1 画面目で鏡の奥行きと世界観をつかませる
- 迷路感を出しつつ、導線は一筆書きで読めるようにする

### 3.3 ヘッダー位置

- `floating overlay`
- 鏡面演出の上に浮く軽いナビにする

### 3.4 ナビゲーション形式

- `world-in-UI`
- 鏡の回廊そのものをナビゲーションとして見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Mirror / Cards / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では反射と奥行きを使って迷路感を強くする
- SP では鏡の数を減らし、視線が迷いすぎないようにする

```
index.html
├── Section 1: Hero (鏡の回廊)
├── Section 2: Profile (幻術師)
├── Section 3: Mirror (鏡の世界)
├── Section 4: Cards (カード)
└── Section 5: Contact
```

---

### 3.7 下層ページの位置づけ

- なし
- 役割のある下層ページは作らず、見せ場はトップ内のセクションへ集約する
