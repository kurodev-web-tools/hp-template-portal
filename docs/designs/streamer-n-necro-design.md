## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 死霊術の館を 1 ページで完結させる

### 3.2 トップの役割

- 1 画面目で沈黙と不穏さを濃く見せる
- 説明は最小限にして、空気感を主役にする

### 3.3 ヘッダー位置

- `top fixed`
- 墓地の重さに負けない標準ヘッダーにする

### 3.4 ナビゲーション形式

- `side dots`
- 墓石の並びのように章移動を見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Ritual / Crypt / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では墓地や燭台の奥行きで重厚感を出す
- SP では暗さを保ちつつ、可読性を優先する

```
index.html
├── Section 1: Hero (召喚の儀式)
├── Section 2: Profile (ネクロマンサー)
├── Section 3: Army (アンデッド軍団)
├── Section 4: Tombs (古代の墓)
└── Section 5: Contact
```
