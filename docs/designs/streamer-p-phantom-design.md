## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 怪盗の潜入体験を 1 ページで見せる

### 3.2 トップの役割

- 潜入前の緊張感と遊び心を作る
- 怪盗像、戦略、実績、連絡先を 1 画面で見せる
- 下層を増やさず、潜入の流れで読ませる

### 3.3 ヘッダー位置

- `floating overlay`
- 影の上に浮かぶ軽い導線にする

### 3.4 ナビゲーション形式

- `section cards`
- 予告状や作戦カードのように移動させる
- カード選択そのものを作戦準備の感覚に寄せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Hideout / Heist / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では屋根裏や影の奥行きを強く出す
- SP では見出しと CTA を優先し、影表現は減らす
- PC は影の層と奥の窓を活かす
- SP はカードの数を絞って、閲覧のテンポを守る

```
index.html
├── Section 1: Hero (屋根裏)
├── Section 2: Profile (怪盗)
├── Section 3: Heist (盗品)
├── Section 4: Notice (予告状)
└── Section 5: Contact
```

### 3.7 下層ページの位置づけ

- 下層ページは作らず、潜入の章立てで完結させる
- `Heist` は作戦・成果物・盗品の章、`Notice` は予告状の章として扱う
