## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 壊れたデータ空間を 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で不安定さと切れ味を同時に見せる
- 情報は絞り、ノイズが主役になるようにする

### 3.3 ヘッダー位置

- `top fixed`
- エラー画面の邪魔をしない最小ヘッダーにする

### 3.4 ナビゲーション形式

- `floating overlay`
- 画面の乱れの中でも位置を把握できる軽い導線にする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Corruption / Code / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC ではノイズや RGB シフトの層をはっきり見せる
- SP ではエフェクトを抑え、読みやすさと警告感を優先する

```
index.html
├── Section 1: Hero (エラー画面)
├── Section 2: Profile (壊れたデータ)
├── Section 3: Corruption (崩壊度)
├── Section 4: Code (コード)
└── Section 5: Contact
```
