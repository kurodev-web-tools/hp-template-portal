## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 集会場からクエスト完了までを 1 ページで見せる

### 3.2 トップの役割

- 1 画面目で緊張感と探索の始まりを伝える
- 先に世界の広がりを見せて、導線は控えめにする

### 3.3 ヘッダー位置

- `top fixed`
- クエストボードの上に置ける標準ヘッダーにする

### 3.4 ナビゲーション形式

- `section cards`
- 章移動をクエスト選択のように見せる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Weapons / Monsters / Quests / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC ではクエストボードと武器展示の密度を確保する
- SP ではボードを縦に整理し、狩猟準備の分かりやすさを優先する

```
index.html
├── Section 1: Hero (クエスト受注)
├── Section 2: Profile (ハンター)
├── Section 3: Weapons (武器紹介)
├── Section 4: Monsters (モンスター図鑑)
├── Section 5: Quests (クエスト一覧)
└── Section 6: Contact
```
