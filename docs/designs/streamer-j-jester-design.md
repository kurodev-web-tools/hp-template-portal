## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 混沌と狂気を 1 ページで完結させる

### 3.2 トップの役割

- 1 画面目で遊び心と読みやすさを両立させる
- 軽快な印象を先に作り、情報は小気味よく見せる

### 3.3 ヘッダー位置

- `floating overlay`
- ピエロの舞台を邪魔しない軽い固定ナビにする

### 3.4 ナビゲーション形式

- `section cards`
- トランプやショーの幕間のように移動させる

### 3.5 下層ページ構成

- なし
- Hero / Profile / Show / Chaos / Contact はトップ内で完結させる

### 3.6 PC / SP の見せ方

- PC では色数と不穏さの対比を強くする
- SP では情報量を整理し、見出しの可読性を優先する

```
index.html
├── Section 1: Hero (ジョーカー)
├── Section 2: Profile (道化師)
├── Section 3: Chaos (混沌度)
├── Section 4: Clock (時計)
└── Section 5: Contact
```
