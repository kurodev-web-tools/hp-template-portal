## 3. ページ構成

### 3.1 レイアウトモード

- `LP single page`
- 神社の境内を 1 ページで巡る構成にする

### 3.2 トップの役割

- 1 画面目で境内の入口感と狐火の気配を見せる
- 世界内 UI と導線を一体化して、迷わず巡れるようにする

### 3.3 ヘッダー位置

- `side panel`
- 右側の狐火ナビと合わせて世界内 UI に寄せる

### 3.4 ナビゲーション形式

- `world-in-UI`
- 狐火案内をそのままセクション導線にする

### 3.5 下層ページ構成

- なし
- Hero / Profile / Powers / Shrine / Stream / Contact はトップ内で完結させる

### 3.5 PC / SP の見せ方

- PC では参道の奥行きと鳥居のレイヤーを活かす
- SP では参道の導線を簡略化し、配信者情報を先に読めるようにする

```
index.html
├── Section 1: Hero (鳥居前)
├── Section 2: Profile (妖狐の正体)
├── Section 3: Powers (九尾の力)
├── Section 4: Shrine (神社)
├── Section 5: Stream
└── Section 6: Contact
```

### ナビゲーション

**狐火案内**
- 右側に狐火（青白い火）が浮かぶ
- スクロールで火が先行して導く
- 各セクションで火が集まる

## 4. セクション詳細

### Section 1: Hero

**レイアウト**: 神社の鳥居前

**構成**:
- **背景**: 夜の神社、大きな鳥居
- **狐火**: 青白い炎が複数浮遊
- **配信者**: 妖狐キャラ（九尾の姿）
- **紙垂**: 風に揺れる

**3D要素**:
```typescript
// 鳥居
const Torii = () => {
  // 朱色の鳥居
  // スクロールで近づく
};

// 狐火
const FoxFire = () => {
  // 青白い炎が揺れる
  // パーティクルで揺らめき
};

// 九尾
const NineTails = () => {
  // 9本の尻尾が揺れる
  // 毛並みの表現
};
```

### Section 2: Profile

**レイアウト**: 妖狐の人間形態

**構成**:
- 妖狐としての経歴（歳：XXX年）
- 神社の守り狐としての役割
- 九尾の力（開放度）
- 好きな供物（好きなもの）

### Section 3: Powers

**レイアウト**: 九尾の力解放

**構成**:
- 9本の尻尾、それぞれの力
- 各尻尾が色と能力を持つ
- 開放度（配信実績）で点灯
