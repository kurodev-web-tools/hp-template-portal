# Streamer Renewal Plan

## Purpose
- `streamer` カテゴリ全体の renewal 方針を整理する
- A〜Z 各テンプレートの renewal 方向性を揃えつつ、演出や体験の重複を避ける
- 今後の個別 `DESIGN.md` や renewal 実装時の上位方針として使う

## Category Direction
- `streamer` は見た目の差別化自体はすでに十分ある
- renewal では「世界観を強くする」だけでなく、「参加したくなる配信体験」に寄せる
- 静的な 1 ページ紹介から、配信中 / 待機中 / アーカイブ視聴 / コミュニティ参加まで含めた体験へ更新する

## Renewal Goals
- `Live感` を強める
  - 配信中、待機中、次回告知、アーカイブ公開など時間状態を UI に持たせる
- `参加導線` を明確にする
  - 視聴、通知、Discord、予約、イベント参加、アーカイブ導線を行動単位で分ける
- `世界内UI` を強める
  - セクション一覧ではなく、そのテンプレートの世界観に合った操作面として見せる
- `動きの質` を最適化する
  - 派手なアニメーションの量ではなく、テーマに合った反応速度、間、収束で差別化する

## Differentiation Rules
- パターンが近くても、主役になる体験装置はテンプレートごとに 1 つへ絞る
- 同系統テンプレートで同じエフェクトやアニメーションを流用しない
- 似た UI を使う場合でも、反応対象、動きの速度、見せる情報、CTA の文脈を変える
- renewal の評価基準は「カテゴリ内で並べたときに混同しないか」を優先する
- `DESIGN.md` は新規作成時または renewal 着手時に、そのテンプレート単位で追加する

## Priority Candidates
- `a`
  - ネオン表現よりも「深度のある配信空間」に振る
  - レイヤー視差、奥行きグロー、焦点移動を主役にする
- `e`
  - esports の競技感を最も伸ばしやすい
  - 試合前 / 配信中 / 試合後で状態切り替えを見せる
- `j`
  - ラウンジ回遊型の体験へ寄せやすい
  - セットリスト、席予約、アーカイブ視聴を店内導線として見せる
- `q`
  - RPG UI を最も完成度高く伸ばせる
  - クエスト受注、進行、報酬、コミュニティ参加を一体化できる
- `s`
  - steampunk の機構感を UI レベルまで引き上げやすい
  - ギア装飾ではなく、圧力や伝達で情報が動く構造へ寄せる
- `u`
  - 閲覧体験の更新幅が大きい
  - ドラッグ、スナップ、擦れでストリート感を強められる
- `w`
  - ファンタジー表現を魔導書 UI に整理しやすい
  - 呪文選択、章立て、記録閲覧を体験の中心に置ける
- `z`
  - 最も静かな renewal 候補
  - 呼吸、余白、最小反応を価値として再設計できる
